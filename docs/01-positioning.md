# Positioning Aditek

## Ringkasan

> Aditek membantu perusahaan di Jabodetabek merancang, membangun, dan menjalankan
> sistem operasional dan keamanan yang terintegrasi — dari desain arsitektur
> sampai tim klien benar-benar memakainya.

## Prinsip

1. **Jual sistem, bukan barang.** Hardware (kamera, reader, controller) adalah komponen
   dari sistem. Yang dijual adalah desain, integrasi, implementasi, training, dan support.
2. **End-to-end.** Survey/konsultasi → desain arsitektur → implementasi → training → support.
3. **Terintegrasi.** Nilai tambah utama ada di hubungan antar sistem:
   - Access control → data absensi → HR/payroll di ERP
   - CCTV ↔ log akses (event dicocokkan dengan rekaman)
   - Aplikasi workspace (Spaces) ↔ akses ruangan ↔ data karyawan

## Tiga sistem

| Sistem | Cakupan |
|---|---|
| Security | Access control, CCTV/surveillance, visitor management, integrasi, kepatuhan UU PDP |
| ERP | Alur bisnis end-to-end: sales, purchasing, inventory, sampai accounting |
| Workspace | Produk **Spaces**: modul otomasi pekerjaan ringan kantor (mis. booking ruang meeting) |

## Target pasar

- Perusahaan menengah di Jabodetabek: kantor, gudang/distribusi, manufaktur ringan
- Pembuat keputusan: owner, GM operasional, HR/GA, finance, IT manager

## Model pendapatan

- Proyek implementasi (desain + instalasi + integrasi)
- Recurring: maintenance/SLA, lisensi Spaces, support bulanan

## Risiko yang dijaga

- Beban after-sales hardware → SLA tertulis, kapasitas teknisi
- Scope creep ERP → scope per fase di kontrak
- Data pribadi (CCTV, biometrik) → implementasi sesuai UU PDP (UU No. 27/2022)
