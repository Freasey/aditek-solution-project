# Rencana Teknologi Website

> Status: **rencana**, belum dieksekusi. Desain dibuat dulu sebagai HTML statis di `design/`.

## Rekomendasi: Astro

- Setiap halaman di-build jadi HTML statis: cepat dan mudah dibaca Google.
- Struktur file mengikuti sitemap (`/security-system`, `/erp-system`, `/workplace-management`).
- Blog `/insights` bisa ditulis dalam Markdown.
- Hosting murah atau gratis (Vercel / Netlify).
- Desain HTML di `design/` bisa dipindah langsung menjadi komponen Astro.

## Alternatif

| Pilihan | Cocok kalau |
|---|---|
| Next.js | Website dan aplikasi (mis. Spaces) digabung dalam satu proyek |
| WordPress | Tim non-teknis edit semua konten lewat dashboard |
| Website builder | Cepat tanpa coding, dengan biaya bulanan dan kontrol SEO terbatas |

## Pertanyaan terbuka

- Siapa yang akan mengelola konten website: tim teknis atau non-teknis?
- Perlu CMS (dashboard edit konten) atau cukup Markdown?
